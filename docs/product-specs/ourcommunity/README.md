# ourcommunity 제품 준비 패키지

상태: 검토용 초안 · 2026-10-29 · 시간 기준 `Asia/Seoul`

후속 상태: 사용자의 “개발까지 쭉 해봐” 요청으로 로컬 초기 제품 구현을 진행한다. 아래는 **개발 승인 이전 준비 기록**이다. 최신 실행 방법과 검증은 [저장소 안내](../../../README.md)와 [구현 기록](../../implementation/local-product.md)을 따른다. 연구 게이트가 통과한 것은 아니다.

목표는 **스포츠를 직접 즐기는 사람들이 우리 앱에서 지속적으로 소통하고, 참여한 커뮤니티·시설을 함께 꾸미고 키우는 경험**이다. 그룹 채팅·공지·일정·참가와 공동 성장 경험을 연결한다. 러닝 우선과 한국은 준비용 가정이며 종목 우선순위·도시·확보 그룹은 미정이다. 디지털 공동 공간은 저위험 제안이고 실물 시설 지원은 승인되지 않았다.

이 준비 문서를 작성한 시점에는 `kee_agent`에서 가져온 개발용 하네스만 있었으며 서비스 코드·사용자·운영 성과는 없었다. 당시 변경은 로컬 문서에 한정했다. 후속 구현 승인과 구현 가정은 근거 기록의 E15/D11–D12에 별도로 남긴다.

## 한 페이지 제품 요약

**핵심 문장(제안): 대화를 공개하는 게 아니라, 함께한 시간이 만든 공간을 보여주는 스포츠 커뮤니티.**

| 핵심 화면 후보 | 하는 일 |
|---|---|
| 우리 그룹 공간 | 공동 기념물·장식과 최근 분위기를 구분해서 보여준다. 비회원은 공개 동의된 공간과 보호된 단계만 보고 원문·개인 접속은 보지 못한다 |
| 그룹 대화 | 비공개 채팅, 공지, 안읽음·뮤트·알림. 대화 속 일정 카드에서 참여로 연결한다 |
| 일정·참가 | 모임 정보, 정원/대기/취소, 변경 확인, 출석과 본인 이력 |
| 함께 꾸미기 | 검증된 출석·도움 등 기여의 이유, 공동 애셋과 장식 제안/합의. 개인 랭킹·금전 보상 없음 |
| 내 활동·운영/안전 | 역할별로 알림·개인정보·가입·출석·신고·차단·기여 정정·삭제를 처리한다 |

첫 범위 제안은 **한 그룹의 대화와 운동·도움이 작은 공동 공간의 변화로 이어지는 최소 루프**다. 그룹 채팅·공지·알림·일정/참가·기본 안전 운영과 최소 공동 기념물을 함께 검증한다. 활기 공개는 집계 보호/고지 조건을 만족한 선택 기능이다. 전체 DM·통화·GPS·PG·쇼핑·WOD 전문 기록·유료/거래 재화는 포함하지 않는다.

개발 순서는 먼저 대상/전환 이유·공동 성장 의미·플랫폼 과업을 검증하고 Gate 0–5를 통과한 뒤, **인증·그룹/권한 → 채팅·복구·알림 → 일정·정원·출석 → 공동 기여/공간·보호된 활기 → 통합 QA·안전/복구 검증**이다. 공개/배포는 별도 단계다. 현재는 코드 없이 22개 수용 기준과 36개 QA 시나리오를 준비했다.

중요한 결정 3개는 아래 ‘우선 필요한 결정’에 모았다. 추천은 사용자 확정과 구분한다.

## 현재 판정

- 제품 Gate 0: **Blocked** — 첫 세그먼트·검증 지역·플랫폼 요구와 성공/실패 기준이 승인되지 않음.
- Gate 1: **Blocked** — 관리 작업에서 전달된 공식 기능 자료는 있으나 미충족 고객 문제와 독립적인 수요 근거 부족. 이 환경의 직접 웹 접근은 프록시 403.
- Gate 2: **Blocked** — 고객 인터뷰와 실제 행동 증거 없음. 조사 실행과 외부 연락도 이번 범위가 아님.
- Gate 3–5: **Blocked by prerequisites / 미평가** — 사업성·UX·보안·운영 검증과 사용자 결정이 필요함. PRD/ADR 초안을 작성했다고 Build Readiness를 통과시키지 않음.
- 문서 L1: [검토 결과](review-report.md)와 구분한다. 문서의 통과는 제품 Gate 통과가 아니다.

`AGENTS.md`의 Opportunity/Product/Solution Gate와 이 패키지의 숫자 Gate는 서로 다른 이름 체계다. 이 패키지의 `Gate 0–9`는 `product-harness-2026` 기준이며 대응표는 [실행 계획](execution-qa.md)에 있다.

## 우선 필요한 결정

1. 첫 검증 커뮤니티와 지역: **한국의 접근 가능한 러닝 크루 우선, 박스는 비교 후보**를 임시 추천. 도시·확보 그룹·종목 선택은 미확정이다.
2. 기기·설치·알림 요구: **네이티브/크로스플랫폼 앱과 PWA를 초대→가입→첫 대화→알림 복귀 과업으로 비교 후 선택**을 추천. 모바일 웹 우선은 철회된 임시 가정이다.
3. 공동 공간과 첫 기여의 표현: **공동 디지털 클럽 공간, 출석·도움 등 서로 다른 기여를 표현하는 소수 애셋**을 비교 검증할 것을 추천. 미술 스타일·해금 규칙·기여 가중치는 미정이다.

답변이 없어도 초안 검토는 가능하다. 제품 대상·플랫폼을 확정하거나 실제 인터뷰·구현을 진행할 권한으로 간주하지 않는다. 과금·운영 예산은 이후 사업 검증에서 결정한다.

# Product specifications

승인된 제품 brief와 기능 사양의 index다. 새 사양은 날짜와 상태를 파일명 또는 frontmatter에 기록한다.

필수 항목:

- 대상 사용자와 해결할 문제
- 가치 제안, 범위와 비목표
- 주요 흐름과 수용 기준
- 데이터·권한·결제·스토어 영향
- discoverability와 측정 적용 판정
- 성공 지표, guardrail, 중단 조건
- 남은 가정과 담당자

실행 순서가 복잡하면 [`../PLANS.md`](../PLANS.md)에 별도 계획을 만든다.

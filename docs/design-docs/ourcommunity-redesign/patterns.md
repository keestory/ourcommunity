폐기한 임시 패턴: 반복되는 큰 집 그림, 소개 문구 뒤로 밀린 입력창, 같은 둥근 카드와 약한 CTA, 설명만 있는 꾸미기. 기존 미확정 스타일을 사용자 취향으로 취급하지 않는다. 모든 카드를 금지하는 일반 규칙도 만들지 않는다.

유지할 패턴: 권한 기반 탐색, 공통 확인창, 비동기 저장 성공 전 입력 보존, 가상 데이터 표시, 최근 활기와 영구 기념물 분리. 정적 audit 무결점은 제품 사용성이나 취향 승인과 별개의 결과다.

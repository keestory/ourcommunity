# 로컬 제품 구현·검증 결과

이 문서는 최초 로컬 구현의 기준 기록이다. 이후 게시 승인과 체험 모드의 최종 79개 Python·11개 브라우저 검증 및 공개 배포 제한은 [체험 배포 기록](preview-deployment.md)을 따른다.

검증일: 2026-10-29 UTC / 2026-10-30 Asia/Seoul. 기존 작업과 저장소에서 개발했으며 원격 푸시·배포·외부 계정 생성·실제 사용자 데이터 전송은 하지 않았다. 고객 발견 Gate 0–2는 계속 **Blocked**, 로컬 구현과 아래 기술 검증은 **Pass**다. 공개 출시 준비 완료를 뜻하지 않는다.

## 구현된 흐름

- 로컬 계정·세션과 가상 운영자/회원 체험 로그인. 현재 그룹 멤버십·역할·CSRF·요청 출처를 서버에서 검사한다.
- 비공개 텍스트 채팅, 페이지 조회, 재시도 중복 방지, 삭제 표시, 읽음 커서, 운영자 공지, 신고·대화 차단·차단 해제.
- 초대 링크 → 로그인/가입 → 원래 초대 복귀 → 그룹 가입. 새 가입·재가입은 과거 대화를 열지 않으며 탈퇴·강퇴 후 서버 접근을 막는다.
- 모임 생성·참가·취소·정원·대기·30분 자리 제안 수락·전체 취소. 한국 시간 입력을 UTC 저장과 명시적으로 연결한다.
- 운영자의 타인 출석 확인·정정, 감사 기록, 하루 한 번의 검증된 참여를 통한 공동 이정표·벤치·나무. 개인 순위·대화량 보상·휴식 벌점은 없다.
- 2D 공동 공간, 팔레트 선택, 영구 기념물과 최근 분위기 분리. 공간 공개와 개인 집계 동의는 별개이며 기본은 꺼짐. 공개 응답에는 원문·개인·정확한 활동 수·시각을 넣지 않는다.
- 앱 안 공지·모임 취소·자리 제안 알림과 뮤트. 외부 푸시가 연결됐다고 표시하지 않는다.

서버는 FastAPI/SQLite, 화면은 React/TypeScript/Vite다. 기존 Python 환경을 활용하면서 외부 서비스 계정 없이 실제 저장·권한·동시성·브라우저 동작을 검증할 수 있어 선택했다. 플랫폼 최종 결정이 아닌 가역적 로컬 구현이다. [실행 안내](../../README.md), [설계와 한계](local-product.md), [디자인 원본](../../DESIGN.md), [상호작용 계약](../../UX-CONTRACT.md)을 참고한다.

브라우저 시나리오는 화면·접근성, 메시지 저장/응답 유실 재시도/초안/삭제, 모임 생성/필드 오류/KST/신청/취소, 공지/공개 선택/출석 정정/성장, 초대/가입/이력/탈퇴, 늦은 세션 응답, 이전 대화 로딩 중 초안, 저장 중 입력·이동 보호, 신고·상호 대화 차단을 다룬다. 모바일 주요 화면과 대화상자의 axe 검사는 위반 0이며, 취소된 모임 행과 키보드로 접근하는 감사 기록도 확인했다. 별도의 로그인 320px 검사에서도 axe 위반·가로 넘침·외부 요청 호스트가 없었다. 이는 실행한 화면 범위의 결과다.

백엔드는 그룹 간·직접 ID 접근, CSRF/Origin/Host, 현재 멤버십, 메시지 중복/삭제/페이지, 6명 동시 정원 경쟁, 대기 제안의 수락/만료, 출석 자기 승인 금지, KST 일일 상한, 공개 집계의 동의·최소 인원·지연·철회 등을 시험했다. 테스트는 임시 DB와 가상 데이터만 사용한다. 브라우저 테스트는 실행 중인 데모 서버가 있으면 재사용하므로 시험용 메시지·모임을 생성한다.

## 독립 검토에서 수정한 결함

| 발견 | 수정 및 재검증 |
|---|---|
| 마지막 초대 사용 후 가입 응답 유실 재시도 404 | 이미 활성 멤버인 동일 계정의 재시도 성공. 사용 횟수 증가·탈퇴 후 재가입 권한은 주지 않음 |
| 뮤트한 대기자에게 자리 알림 생성 | 좌석 제안은 유지하고 새 알림만 생략 |
| 탈퇴·강퇴자의 과거 출석 정정 불가 | 권한 있는 운영자의 부정 정정 허용. 긍정 승인은 현재 멤버만, 자기 승인 금지·감사 유지 |
| 데모 종료 후 기존 샘플 인증 유지 | 고정 샘플 ID 9명의 로그인·기존 세션 차단. 동일 username의 일반 로컬 계정은 구분 |
| 늦은 익명 세션 응답이 새 로그인을 덮음 | 요청 세대·취소 보호; 로그인/로그아웃/만료 시 이전 요청 무효화 |
| 이전 채팅 페이지 로딩 중 초안 보호 해제 | 로딩 중에도 이동 보호 유지; 느린 응답 회귀 테스트 |
| 취소 행 대비·랜드마크·스크롤 키보드 접근·모바일 입력 배치 | 스타일/의미 구조/포커스 개선, axe와 실제 입력 위치 재검증 |

독립 검토자가 백엔드 65개와 프런트 경합 회귀 2개를 별도로 재실행했다. 마지막 검토 범위에서 남은 차단 결함은 없다. 실제 iOS/Android 기기·보조기술 전반·부하·실제 사용자 행동·외부 인증/푸시·운영 배포는 검증하지 않았다.

## 화면 증거

화면은 별도의 깨끗한 샘플 DB에서 촬영한다. 기존 작업 DB를 삭제하거나 초기화하지 않는다. 사진 속 크루·사람·대화·출석은 모두 가상 데이터이며 성과가 아니다.

## 남은 범위

외부 인증·복구, 휴대폰 푸시, 사진, 일정 편집, 그룹 생성, 소유권 이전, 계정 삭제·보관 정책, 운영 인력과 호스팅은 연결하거나 완료하지 않았다. 알림과 채팅은 폴링이며 대기 제안 만료는 관련 요청에서 계산한다. 실제 기기·고객 검증 후 플랫폼과 정책을 정해야 한다. 이번 요청에는 원격 푸시·배포가 포함되지 않는다.

변경 파일 전체는 [변경 목록](changed-files.txt)에 기록한다. 기존 하네스의 역할·실행 코드는 보존했고 제품 코드·테스트·문서를 별도 경로에 추가했다. 기존 준비 문서 14개는 연구 기록으로 유지한다.

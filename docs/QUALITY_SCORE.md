# 품질 스코어

> 각 도메인과 아키텍처 레이어의 품질 등급을 추적합니다.
> QualityScorer 에이전트가 주기적으로 업데이트합니다.

## 등급 기준

| 등급 | 설명 |
|------|------|
| A | 우수 — 테스트 커버리지 90%+, 린트 위반 0, 문서 최신 |
| B | 양호 — 테스트 커버리지 70%+, 경미한 린트 위반, 문서 대부분 최신 |
| C | 보통 — 테스트 커버리지 50%+, 일부 아키텍처 위반 |
| D | 미흡 — 테스트 부족, 아키텍처 위반 다수, 문서 부재 |
| F | 위험 — 즉각적인 개선 필요 |

## 현재 품질 등급

| 도메인 | 등급 | 테스트 커버리지 | 린트 위반 | 문서 상태 | 최종 평가 |
|--------|------|----------------|----------|----------|----------|
| orchestrator | - | 미측정 | 0 | 최신 | 공개 import·workflow·gate 경계 테스트 통과 |
| agents | - | 미측정 | 0 | 최신 | review level·진단·dispatch 회귀 테스트 통과 |
| linters | - | 미측정 | 0 | 최신 | architecture·naming·structure 검사 통과 |

등급은 커버리지 측정 전까지 확정하지 않는다. 2026-10-10 기준 전체 테스트 30개와 로컬 린터를 통과했으며, 모든 Python 파일은 300줄 이하이다.

# Active execution plans

현재 진행 중인 다단계 계획을 저장한다. 계획이 완료되면 결과와 검증 증거를 기록하고 `../completed/`로 이동한다.

- [ourcommunity 발견·검증 및 후속 의존성](../../product-specs/ourcommunity/execution-qa.md) — 연구 Gate는 검증 대기. 고객 조사와 출시 승인을 뜻하지 않는다.
- [ourcommunity 로컬 제품 구현](../../implementation/local-product.md) — 사용자 후속 요청으로 개발 승인. 저장·권한이 있는 수직 기능과 브라우저 검증을 진행하며 푸시·배포는 범위 밖이다.
